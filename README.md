# 🔢 Number to Arabic Words Converter | تحويل الأرقام إلى كلمات عربية

أداة بسيطة ومستقرة مكتوبة بلغة **Python** تقوم بتحويل الأرقام العددية (مثل `520`) إلى ما يقابلها من الكلمات المكتوبة باللغة العربية (مثل `خمسمائة وعشرون`). مفيدة جداً في تطبيقات الفوترة، الحسابات، وتفقيد المبالغ المالية.

---

## 🚀 المميزات (Features)

- **دقة لغوية:** تحويل الأرقام بدقة مع مراعاة قواعد اللغة العربية (التذكير والتأنيث، الإعراب الأساسي).
- **سهولة التكامل:** يمكنك دمج السكريبت بسهولة داخل أي مشروع Python آخر.
- **دعم الأعداد الكبيرة:** التعامل مع نطاقات واسعة من الأرقام.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Language:** Python 3.x
- **Libraries:** `num2words` (أو اذكر المكتبات التانية لو استخدمت حاجة زي Pillow أو مكتبات مخصصة)
